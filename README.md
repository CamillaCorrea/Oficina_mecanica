OFICINA MECÂNICA
Projeto de banco de dados para uma oficina mecânica.

ARQUIVOS
- `DDL_oficina.sql`: criação do banco de dados e das tabelas.
- `script_oficina.sql`: inserção, consulta, atualização e exclusão dos dados.
- `der_oficina_mecanica.png`: diagrama entidade-relacionamento.

TABELAS
- Clientes
- Mecânicos
- Veículos
- Ordens de serviço
